Overview

The NMR Prediction Benchmark provides standardized datasets and evaluation metrics for four key NMR prediction tasks. Our goal is to advance the development of machine learning models for computational NMR spectroscopy.

Task 1: NMR2SMILES - Structure Elucidation

Description

Structure elucidation from NMR spectra is a fundamental inverse problem in chemistry. This task evaluates models on predicting molecular structures (SMILES) from NMR spectral data, using both sequence-level and token-level metrics.

Task Details

  • Input: NMR spectral features
  • Output: SMILES molecular representation
  • Methods: Search-based, Transformer-based, Diffusion-based

Evaluation Metrics

  • Sequence-Level: Top-1, Top-5, Top-10 exact match accuracy (%)
  • Token-Level: Top-1, Top-5, Top-10 token accuracy (%)
  • Fingerprint Similarity: Morgan, Torsion, Atom-Pair (Tanimoto & Cosine)

Task 2: NMR2Func - Functional Group Prediction

Description

Multi-label functional group prediction from NMR spectra. This task evaluates models' ability to identify chemical functional groups present in molecules based on their NMR spectral signatures.

Task Details

  • Input: NMR spectral features
  • Output: Multi-label functional group classifications
  • Challenge: Imbalanced class distribution

Evaluation Metrics

  • Macro/Micro Accuracy: Precision at functional group level
  • Macro/Micro Recall: Sensitivity of predictions
  • Macro/Micro F1: Harmonic mean of precision and recall
  • Subset Accuracy: Exact match of all labels

Task 3: NMR2Tox - Toxicity Prediction

Description

Multi-label toxicity prediction from NMR spectra. This task evaluates models on their ability to predict potential toxicity hazards of chemical compounds directly from spectral data, which is important for drug safety and environmental chemistry.

Task Details

  • Input: NMR spectral features
  • Output: Multi-label toxicity classifications
  • Challenge: Highly imbalanced dataset with rare toxic classes

Evaluation Metrics

  • Macro/Micro Accuracy: Overall prediction accuracy
  • Macro/Micro Recall: Sensitivity to toxic compounds
  • Macro/Micro F1: Balance between precision and recall
  • Subset Accuracy: Complete toxicity profile match

Task 4: SMILES2NMR - Spectral Simulation

Description

NMR spectral simulation from molecular structures (SMILES). This forward prediction task evaluates models on generating realistic NMR spectra for both 1H and 13C nuclei, which is crucial for structure verification and experimental planning.

Task Details

  • Input: SMILES molecular representation
  • Output: Simulated NMR spectrum
  • Nuclei: 1H and 13C
  • Methods: DFT-based (Cascade), Neural networks (NMRNet)

Evaluation Metrics

  • Validity: Chemical validity of generated spectra (100%)
  • Set Similarity: Peak set overlap with ground truth
  • Vector Similarity: Spectral vector cosine similarity
